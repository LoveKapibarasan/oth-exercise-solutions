Note:The length of a triple(x,y,z)isℓ(x,y,z):=|bin(x)|+|bin(y)|+|bin(z)|, where bin(a)for a
natural numberadenotes the binary representation ofa. Note that forx∈Nit holds 2 |bin(x)|−1 ≤x<
2|bin(x)| .
Solution:Idea: Perform exponentiation step by step, stopping if the result would become too long.
Handle special cases. Care is needed forx=1.
def a(x, y, z):
if x == 1: return z == 1
if x == 0: return (z == 0 and y != 0) or (y == 0 and z == 1)
if y == 0: return z == 1
prod = x
while prod < z and y > 1:
prod = prod * x
y = y - 1
return prod == z and y == 1
Justification for polynomial running time:
1. Up to the while-loop, only a constant number of steps are required.
2. Just before each multiplicationprod = prod * x, it always holds thatprod≤zandx≤z.
Thus, each individual multiplication requires at most 2|z|2 ≤2n 2 ∈O(n 2)steps.
3. We determine the number of loop iterations. After iterationi, it holdsprod=x i+1. The loop
terminates oncey==1 orprod≥z. In caseprod≥z, the loop terminates afteriiterations,i
is the smallest natural number withprod=x i+1 ≥z, i.e., the number of loop iterations is at
mosti=⌈log x z⌉ −1≤logz(taking the log on both sides of the inequality).
So the number of loop iterations is min(y, logz), which is inO(n)(aszis part of the input, it
holds logz≤n, wherenis the input).
4. All other operations require constant running time.
5. This results in a total running time ofO(n 3).

• LetG= (V,E)be an Eulerian graph. By definition, there exists an Euler tour (a closed
circuit) that traverses every edge of the graph exactly once.
• Consider an arbitrary nodev∈V. Each time the tour enters the nodevvia some edge, it
must leavevvia adifferentedge, because the tour continues and every edge is used exactly
once.
• Every such “visit” (entering and leaving) consumes exactly two edges incident tov. There-
fore, each visit contributes exactly 2 to the degree of the node.
• Since the tour starts and ends at the same nodev 0, the very first outgoing edge and the very
last incoming edge atv 0 also form a paired visit.
• Because the Euler tour containseveryedge inGexactly once, the total degree of each node is
completely determined by these pairwise traversals. Consequently, the degree of every node
must be a multiple of 2, meaning it is even.
Part 2: If each node inGhas an even degree,Gis Eulerian (⇐)
• We prove this constructively. LetGbe a connected graph in which every node has an even
degree.
• Start at an arbitrary nodev 0 and walk along unused edges, marking each traversed edge
as “visited”.We continue this walk until we reach a node from which we cannot leave
(because all its incident edges have been visited).
• Because every node has an even degree, whenever we enter any nodev̸=v 0, we have used
an odd number of its incident edges during the current walk (including the one just used to
enter). Since its total degree is even, there must necessarily be at least one unvisited edge
remaining to leavev.
• Therefore, the walk canneverget stuck at a nodev̸=v 0. It must inevitably get stuck at the
starting nodev 0 (it must get stuck at all as the graph is finite). This guarantees that our walk
forms an initial closed circuitC 1.
• IfC 1 contains all the edges ofG, the proof is complete;C 1 is our Euler tour.
• IfC 1 does not contain all edges, we logically remove all edges ofC 1 fromG. In the resulting
subgraphG ′, every node still has an even degree, because we removed an even number of
incident edges (a matched sequence of entering and leaving) from every node present inC 1.
• Since the original graphGis connected, there must be at least one nodeu∈C 1 that still has
incident, unvisited edges inG ′.
• We now start a new walk fromuinG ′, again walking until we get stuck. By the same logic
as above, this walk will inevitably close into a new circuitC 2 atu.
• We can now “splice”C 2 intoC 1: The new, enlarged tour followsC 1 up tou, then completely
traversesC 2 until returning tou, and finally follows the remainder ofC 1.
• Since the number of edges inGis finite, we can continuously repeat this process of enlarging
the circuit until all edges are consumed. The final result is a single closed circuit containing
every edge exactly once—an Euler tour.
